# Retail Sales EDA Project

## Files
- `Retail_Sales_EDA.ipynb` — complete Jupyter Notebook with analysis, charts, observations, and recommendations.
- `retail_sales.csv` — synthetic sample retail transactions to run the notebook immediately.
- `requirements.txt` — Python dependencies.

## Run the project
1. Extract the ZIP file.
2. Open a terminal in the extracted folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start Jupyter:
   ```bash
   jupyter notebook
   ```
5. Open `Retail_Sales_EDA.ipynb` and choose **Kernel → Restart & Run All**.

## Dataset columns
`Transaction ID`, `Date`, `Customer ID`, `Age`, `Gender`, `Product`, `Product Category`, `Quantity`, `Price per Unit`, `Total Amount`.

To use another CSV, replace `retail_sales.csv` with your dataset and adjust column names in the notebook if needed.

## Note
The included CSV is synthetic sample data for practice. Its patterns and findings are not real-world retail statistics.
